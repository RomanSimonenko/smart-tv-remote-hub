# Профиль владельца — первый рабочий этап

Статус: согласовано пользователем 2026-10-12. Основа — раздел 6.11 [ТЗ интерфейса](2026-10-11-product-ui-design.md).

## Цель и границы

Открывать профиль из нижней части бокового меню; редактировать отображаемое имя и выбирать готовую иконку. Сведения принадлежат владельцу установки и доступны одинаково с разных компьютеров. Русский интерфейс и тёмная тема; светлая тема и RU/EN остаются финальным этапом.

Включены: профиль, сохранение имени/иконки, отражение изменений в меню, неизменяемый логин, сведения о текущей сессии и существующий подтверждаемый выход. Загрузки фото нет. Смена пароля — следующий самостоятельный этап с проверкой текущего пароля и отдельно согласованной политикой завершения сессий; активная кнопка до реализации не показывается.

## Проверенное исходное состояние

`Home.tsx` показывает сведения аккаунта в диалоге; `AppSidebar.tsx` выводит логин и не имеет перехода в профиль. `owner` в SQLite хранит логин и хеш пароля. Существующий API сессии возвращает логин и CSRF; API изменения профиля и пароля в просмотренных контрактах и auth routes отсутствует.

## Хранение

Использовать SQLite владельца. Добавить nullable `display_name` и `avatar_id` отдельной миграцией, сохранив существующие данные. Отсутствующее имя отображается как логин, отсутствие иконки — инициалы. Это определённое начальное состояние старых установок.

Альтернатива — хранение в браузере: проще, но профиль различался бы на разных компьютерах и мог исчезнуть при очистке браузера. Для удалённого использования предпочтительно серверное хранение.

## Контракт

Отдельные защищённые `GET /api/profile` и `PATCH /api/profile`; существующие ответы входа и сессии не меняются. PATCH принимает строгий объект с обоими полями: `displayName` и `avatarId`. Имя после удаления внешних пробелов содержит 1–64 Unicode code points. `avatarId` — один из фиксированного списка или null для инициалов; неизвестные значения и поля отвергаются. Отдаётся сохранённый профиль без пароля, хеша и секретов.

Использовать действующие authentication, Origin/CSRF и ограничения запросов; изменения атомарны. Истекшая сессия проходит существующий сценарий повторного входа. Ошибки загрузки/сохранения видны; успех показывается только после ответа сервера. При ошибке черновик сохраняется для повторной попытки.

## Интерфейс и навигация

Кнопка профиля доступна в обоих состояниях меню с понятным названием. Переход сохраняет выбор телевизора, прекращает удержание и освобождает ресурсы камеры через существующий lifecycle; из профиля команды ТВ не отправляются. Модальные подтверждения не обходятся навигацией.

Профиль соответствует согласованной композиции: аватар, имя, роль владельца; поля имени и логина; отдельная строка сохранения. Набор из 16 готовых иконок одной графической семьи: пользователь, кот, собака, олень, робот, ракета, планета, звезда, лист, дерево, гора, солнце, луна, геймпад, наушники, монитор. Возможность вернуть инициалы; выбор имеет доступное название и выбранное состояние. Не использовать произвольный SVG/URL от пользователя.

Форма имеет исходное и редактируемое состояния; сохранение недоступно без изменений или при запросе. При уходе с несохранёнными изменениями требуется подтверждение. В меню имя/иконка обновляются после успешного сохранения. Текущая сессия обозначается «Этот браузер», без выдуманного времени, устройства или IP.

## Проверка

- Миграция существующей базы сохраняет учётную запись и сессии.
- API: чтение/сохранение, границы имени, Unicode, неизвестные поля/иконка, отсутствие сессии, неверные Origin/CSRF и ошибка хранения.
- UI: загрузка/повтор, сохранение/ошибка, инициалы/16 иконок, reload, подтверждение несохранённых изменений, оба состояния меню.
- Навигация: отсутствие команд, прекращение удержания, cleanup камеры, сохранение выбранного ТВ и действующих блокировок.
- Визуальная проверка с синтетическими данными, клавиатурой, длинным именем и узким окном; обязательные проверки репозитория перед завершением.

Уточнение при реализации: вместо лисы используется олень из установленного набора Tabler, чтобы все 16 иконок оставались в одной графической семье. Начальное имя старых установок сохраняет логин без нормализации; строгая нормализация применяется при редактировании.

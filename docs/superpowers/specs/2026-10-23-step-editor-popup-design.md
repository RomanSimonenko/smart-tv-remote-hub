# Редактор шага в одном диалоге

Пользователь выбрал макет с существующим пультом слева и таблицей нажатий
справа. Новая палитра клавиш отклонена: раскладка готового пульта сохраняется.
Выбранный макет: `exec-a7ed5b22-dd7a-4e25-b160-e474243846d8.png`.

- Вместо правой панели шаг открывается в широком модальном диалоге.
- Уточнение по замечаниям пользователя: ширина окна 1000px, поле удержания
  использует те же стрелки с шагом 100мс, что и пауза. Для кнопок без
  удержания поле остаётся пустым, без тире. Действие — «Сохранить шаг».
- Тип и описание сверху; существующий пульт слева; нажатия и условия справа.
- Все настройки нажатия находятся в одной строке: кнопка, пауза, удержание,
  длительность, удаление. Ошибки могут занимать отдельную строку.
- Пульт можно свернуть; кнопки сразу добавляют независимые действия в конец
  последовательности, без вложенного диалога и без команд физическому ТВ.
- Общий RemoteLayout и существующая оболочка пульта — один источник раскладки.
- «Сохранить шаг» проверяет шаг и переносит его в черновик кейса,
  затем закрывает диалог. Сохранение всего кейса остаётся отдельным действием.
- Отмена/Escape/крестик при изменениях показывают подтверждение внутри того
  же диалога. Можно продолжить или отбросить правки шага. Новая пустая заготовка
  при отмене удаляется из черновика; существующий шаг сохраняется.
- Существующие лимиты, порядок действий, удержание, паузы, условия OCR,
  копирование и перетаскивание сохраняются. RU/EN, фокус и клавиатура обязательны.
- Диалог адаптируется к поддерживаемой ширине от1280px; содержимое прокручивается,
  шапка и основные действия остаются доступны. Новые темы не вводятся.
- Текущую пользовательскую вкладку с несохранёнными правками не перезагружать;
  приёмка новой версии в отдельной вкладке и на синтетических сценариях.

Альтернативы: узкая боковая панель не вмещает строку нажатия; два вложенных
диалога затрудняют добавление. Принят один диалог с готовым пультом внутри.

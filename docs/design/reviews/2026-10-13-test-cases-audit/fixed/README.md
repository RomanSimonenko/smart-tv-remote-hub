# Визуальная проверка исправлений

Это снимки реализации с синтетическими данными для проверки семи находок аудита. Они дополняют художественные референсы; актуальные правила приведены в разделе 12 ТЗ. Изменения не затрагивают лимиты данных и сохранение кейсов.

| Находка | Проверка |
|---|---|
| Длинная группа, типографика таблицы | [Список 1558×1248](01-list.png): группа занимает две строки, основной текст 14/20 px |
| Длинный текст шага | [Редактор](02-long-steps.png): двухстрочный обзор и полный текст в параметрах |
| Компоновка при уменьшении окна | [Длинные тексты, 1024×768](03-editor-1024.png), [200 шагов, 1024×768](07-200-steps-1024.png): страница не растёт на весь список, параметры видимы |
| Обрезка меню | [1280×600](04-menu-600.png): меню развёрнуто вверх, все три пункта доступны |
| Действия и прокрутка импорта | [1280×720](05-import.png): нижние кнопки видны, список предпросмотра использует общую прокрутку |
| Подтверждение закрытия | [1280×720](06-confirm-close.png): вопрос и обе кнопки видимы, фокус на продолжении; возврат сохраняет ввод и фокус на «Проверить» |

На широком окне базовая высота строки 60 px. В уменьшенном окне действия переносятся на вторую строку, чтобы не накладываться на текст. Использованы прежние токены поверхностей, границ, текста и акцента; новые оттенки не добавлены.

На пользовательском приложении после пересборки и входа также проверены таблица, пустой редактор и импорт. [Меню на 8081](08-app-8081-menu.png) — пустой редактор без пользовательских сценариев.

Дополнение 2026-10-14: область кнопки выбора растянута на всю строку вместе с отступами и рамкой; кнопки действий находятся над этой областью. Проверены клики у четырёх сторон рамки, фокус и перемещение шагов — 5 E2E прошли, сборка и проверка типов успешны. После пересборки Docker проверены реальные клики у левого и правого края строки на 8081: шаг выбран, кнопка выбора получает фокус. [Синтетический кейс после проверок](09-row-hit-area.png).

Дополнение 2026-10-14: добавлены ручка перетаскивания, линия вставки, автопрокрутка и отмена Escape. Порядок меняется только при отпускании в списке, текст и выбранный шаг сохраняются по идентификатору. Стрелки и сохранение кейса используют общий механизм порядка.

# Настройка нажатий: проверка реализации

Дата: 2026-10-15. Реализован первый этап — наполнение шагов, без запуска команд и захвата камеры.

## Реализовано

В параметрах шага можно собрать несколько действий через существующую раскладку
пульта, применить весь набор, изменить паузы, порядок и удалить действия.
Пульт в редакторе не монтирует сетевой контроллер и не отправляет команды ТВ.
Описательные шаги и импорт без действий по-прежнему допустимы.
Сохранение шага применяется к черновику; сохранение кейса записывает всю версию.

## Проверки

- Полный набор: 1509 тестов прошли, включая 426 web и 466 API.
- Проверка типов и сборка прошли. Сборка сообщает предупреждение Vite о JS chunk
  больше 500 kB; это не ошибка сборки, разделение bundle в этот этап не входит.
- Новые сценарии проверены RED → GREEN: контракт действий, диалог/очередь,
  неприменённые действия редактора и некорректные паузы.
- Ревью нашло несоответствие старого лимита HTTP 2 MiB новым допустимым данным.
  Регрессия воспроизведена HTTP 413; предел увеличен до 8 MiB, тот же тест HTTP 201.
  Авторизация, CSRF и rate limit сохранены; таблица SQLite не изменялась.
- Живое управление: все 141 тест пульта прошли после извлечения визуальной раскладки.

## Приёмка в Docker на 8081

Существующий стенд пересобран без удаления volumes. Через браузер создан отдельный
синтетический кейс «Демо — нажатия пульта», остальные кейсы не менялись.
Сохранение RIGHT/RIGHT/ENTER с паузами 500/500/1000 и безопасное обновление страницы
подтвердили восстановление порядка и значений.

197 добавляемых действий при трёх существующих заполняют лимит 200. Добавление
блокируется, очередь прокручивается внутри окна, страница не прокручивается.
Отмена отбрасывает только новый набор и сохраняет три прежних действия; кейс
остаётся без несохранённых изменений. Escape отбрасывает набор и возвращает
фокус на «Добавить нажатия», не добавляя BACK.

При 1280×720 содержимое модального окна прокручивается, footer виден и доступен,
горизонтального переполнения страницы нет. Временный viewport для сравнения
1484×1060 восстановлен после проверки. Реальные команды ТВ не выполнялись.

## Визуальная сверка

Макеты и фактические экраны сопоставлены рядом при 1484×1060. Подтверждены
компоновка редактора, панель параметров, последовательность и существующая
раскладка пульта. Устранены лишний верхний отступ пульта и размер новой подписи.
Computed styles: accent #79E493, panel #1A222C; новые стили используют токены.

Численные требования и готовый пульт приоритетнее неточностей генерированных
макетов: сохранены реальные размеры кнопок/радиусы и центрированный 0, плоские
общие поверхности вместо декоративных градиентов, стандартный диалог и footer.
Замена клавиши выпадающим списком, случайно показанная на первом макете, не была
согласована и не реализована: можно удалить нажатие и добавить другое пультом.
Сохранённые кнопки неактивны, пока нет изменений, как в существующем редакторе.

Локальные снимки и парные сравнения находятся в игнорируемой `.local/key-sequence-review`;
публичные материалы не содержат пользовательских сценариев и кадров камеры.
Рабочий запуск с выполнением команд и сохранением снимков — следующий отдельный этап.

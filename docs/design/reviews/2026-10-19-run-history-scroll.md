# История запусков: локальная прокрутка списка

Дата: 2026-10-19. По комментарию пользователя закреплены заголовок страницы,
фильтры и заголовки колонок; прокручиваются строки таблицы. Компоновка, палитра
и содержимое сохранены. Последнее требование пользователя уточняет поведение
прокрутки сверх исходного статичного макета 06-runs.png.

Причина: min-height:100dvh позволял области runs расти вместе с таблицей;
у контейнера таблицы не было ограничения по высоте. Исправлены только стили
истории: высота окна, сжимаемая область списка, overflow:auto у tbody и отдельная неподвижная шапка.
Догрузка остаётся видимой вне списка. Остальные экраны не затронуты.

Проверки:
- Новый браузерный тест до исправления упал: таблица не прокручивалась.
- После исправления длинная синтетическая история из 60 строк проверена на
  1138×1248, 1280×720 и 1138×520; тёмная тема, свёрнутая навигация.
  Колёсико прокручивает строки; позиции заголовка, фильтров и шапки стабильны;
  документ не выше окна; кнопка догрузки остаётся в области видимости.
- Пять проверок фильтров и обновления истории прошли; сборка web прошла.
- Impeccable и релевантные рекомендации UI UX Pro Max применены. Ручной
  Impeccable detect выполнен по исходникам: regex-проверка, не полный аудит
  контраста и доступности отрисованной страницы.
- Docker пересобран и обновлён с сохранением рабочего тома. На работающем
  приложении во встроенном браузере при 1138×1248 scrollTop списка изменился
  с 0 до 295; позиции заголовка 24, фильтров 117, шапки 209 px остались прежними,
  высота документа осталась равной 1248 px. Снимок отрисовки осмотрен.

Синтетический скриншот: apps/web/.local/playwright/run-history-scroll.png
(локальный, не включается в репозиторий). Физические команды ТВ и тестовые
прогоны не запускались; история и данные не изменялись. Мобильная компоновка,
светлая тема и иные размеры этим изменением не проверялись.

## Уточнение границы прокрутки

По замечанию пользователя область прокрутки перенесена с общей обёртки таблицы на tbody: полоса начинается под строкой названий колонок. Заголовок и строки используют общую сетку колонок и одинаковый резерв под полосу прокрутки. Регрессионная проверка дополнена проверкой, что верхняя граница прокручиваемой области не выше нижней границы заголовка.

Фон thead покрывает также резерв полосы прокрутки: пустого угла справа нет.
Совпадение фона thead и ячеек закреплено браузерной проверкой; после обновления
Docker подтверждено в пользовательском приложении.

# Редактор с перетаскиванием шагов

Снимки реализации на синтетических данных. Актуальные правила: [ТЗ последовательного редактора](../../../superpowers/specs/2026-10-13-ordered-test-case-editor-design.md), раздел «Перетаскивание шагов».

- [Обычное состояние](01-editor-drag-drop.png): ручка из шести точек слева от номера, прежние кнопки действий и выбор строки.
- [Перенос с автопрокруткой](02-editor-drag-active.png): исходный шаг приглушён, карточка под указателем использует общую палитру. Место вставки обозначается зелёной линией на границе шагов; Escape отменяет жест.

Проверки: 7 браузерных сценариев редактора, 1478 тестов проекта, сборка и проверка типов — успешно. На 8081 проверен перенос первого шага ниже второго и обратно: исходный порядок восстановлен, данные на сервер не записывались.

Независимое ревью управления жестом, индексов вставки и очистки состояния не выявило блокирующих замечаний.

# Настройка нажатий — проект макетов

Статус: согласованная композиция; генерированные изображения, не снимки приложения.
Основа: [ТЗ](../../../superpowers/specs/2026-10-15-step-key-sequences-design.md).

- [Редактор с последовательностью](01-step-key-sequence.png).
- [Выбор клавиши](02-add-key.png).

Пульт остаётся открытым при наборе. Нажатия появляются в последовательности
рядом с ним. «Готово» добавляет набор к шагу, «Отмена» отбрасывает набор этого окна.
Команды телевизору не отправляются.
Повторение клавиши создаёт отдельную запись. Пауза редактируется для каждой записи.
В изображении показана идея дополнительной замены клавиши через список в строке;
это предложение макета, до утверждения не расширяет согласованные требования.

При реализации использовать точные общие цветовые токены и стандартные размеры
контролов из дизайн-ТЗ. Генерированные изображения задают композицию и состояния,
не заменяют численные требования: декоративные градиенты, тени и увеличенные
кнопки пульта с изображения не переносить. Модальное окно при малой доступной
высоте прокручивается внутри, заголовок и закрытие остаются доступны.

Исправление по замечанию пользователя: окно выбора использует существующий пульт
проекта с исходным порядком кнопок, питанием, цветными клавишами и Wink.
При реализации переиспользовать готовый компонент, не рисовать отдельный пульт.

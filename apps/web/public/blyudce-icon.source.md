# БЛЮДЦЕ lab

Собственный знак проекта, согласованный 2026-10-12: серебряное блюдце,
экран и круглое зелёное яблоко с листиком. Изображение выделено из согласованного
визуального концепта с помощью ImageGen, без ручной перерисовки геометрии.
Фон полностью непрозрачный; скругление плитки в интерфейсе задаётся стилями.

`blyudce-icon.png` используется в интерфейсе, как favicon и иконка для домашнего
экрана Apple. Название вкладки и метаданные приложения: **БЛЮДЦЕ lab**. Палитра основана на
`src/styles/tokens.css`: панель `#1A222C`, основной текст `#F2F5F8`, акцент `#79E493`.
Написание названия принадлежит общему компоненту `Brand`: **БЛЮДЦЕ lab**.
